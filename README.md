# Noname Inogai Patches

本仓库维护了一系列针对 [Noname](https://github.com/libnoname/noname) (无名杀) 的自定义补丁。
这些补丁主要涉及国战模式的增强与优化，旧版已经归档至 `inogai-24.10`, `inogai-23.12` 分支。

## 项目信息

- **上游项目**: [Noname (无名杀)](https://github.com/libnoname/noname)
- **许可证**: GNU General Public License v3.0 or later (GPLv3+)

## 变更详情

### 已启用特性

#### 1. 解除联机人数限制

修改了房间创建逻辑，允许房主在只有一人的情况下启动游戏。这对于开发调试和测试非常有用。

- **涉及文件**: `apps/core/noname/ui/create/index.js:3651-3654`

#### 2. 国战OL模式武将池扩展

移除了国战模式仅能选择国战包武将的限制，通过 `get.charactersOL` 获取所有可用武将。

- **涉及文件**: `apps/core/mode/guozhan/src/patch/content.js:585-598`

#### 3. 优化选将数量

将原有的根据人数动态计算选将数（5-7名）的逻辑替换为固定值（16名），提供更多策略选择。

- **涉及文件**: `apps/core/mode/guozhan/src/patch/content.js:603-611`

#### 4. 势力随机平衡

替换了默认的 `randomSort` 方法，采用加权随机算法确保初始选将框中魏、蜀、吴、群雄势力的武将数量相对均衡，避免某一势力武将过多或过少的情况。

- **涉及文件**: `apps/core/mode/guozhan/src/patch/content.js:613-642`

#### 5. 默认联机大厅地址

将默认联机大厅地址从空字符串修改为 `wss://noname.inogai.com`。

- **涉及文件**: `apps/core/noname/library/index.js:35`

## 开发说明

所有变更均采用**非破坏性修改**方式：

- 原始代码逻辑被注释保留，而非直接删除。
- 新增逻辑紧随其后，保持代码结构清晰，便于追踪和回滚。
